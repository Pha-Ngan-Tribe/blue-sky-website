# Blue Sky — Website

The official website for **Blue Sky**, a single-player dungeon crawler.

**Live site:** <https://bluesky.kobranov.dev/>

## Pages

- `index.html` — game overview, screenshots, features, and system requirements.
- `downloads.html` — direct downloads for macOS, Windows, and Linux.
- `style.css` and `img/` — the site's styles and artwork.

This is a static HTML and CSS site. Open `index.html` in a browser to preview it locally; no build tools or server are required.

## Publishing

GitHub Actions publishes the site to GitHub Pages when changes are pushed to `main`. When a game release is published, its platform builds are mirrored to this repository's Releases. The Downloads page links directly to the latest release files.
